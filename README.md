# 📿 ذِكر فلو | DhikrFlow

> A modern, elegant Islamic Tasbih & Dhikr web application designed for mindful remembrance with rhythm cadence assistance, accurate lap tracking, and digital LCD aesthetics.

---

## ✨ Features

- 🎯 **Accurate Lap & Round Tracking (الدورات والعد)**: Mathematical round calculations based on custom targets (e.g., 300 total with target 100 = 3 completed rounds).
- ⏱️ **Session Stopwatch**: Top persistent timer to track your focus session duration with instant pause/resume.
- ⚡ **Auto-Count & Rhythm Cadence (BPM)**: Audio-haptic cadence engine with instant one-click stop and custom tempos.
- 📟 **Digital LCD Display**: Toggle between clean typographic numbers and authentic digital tasbih counter screen font.
- 🫧 **Interactive Percentage Bubble**: Visual completion progress ring with live percentage tracker.
- 🕌 **Themes**: Includes Islamic Emerald (زمرد إسلامي), Onyx Dark, and Light themes.
- 📴 **Offline-First (PWA)**: Works entirely offline with local storage persistence and no data tracking.
- 🌐 **Bilingual**: Full support for Arabic (RTL) and English.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Audio & Haptics**: Web Audio API & Vibration API
- **Icons**: Lucide React
